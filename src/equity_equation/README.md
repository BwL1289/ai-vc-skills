# equity_equation

This script grew into the equity calculator in [`equity-calculator/`](../../equity-calculator/). It works the same investor test from Paul Graham's "The Equity Equation" exactly, plus six more scenarios, with a command line, an MCP server and an agent skill.

The original script is in the repository's history: [`src/equity_equation/` before the move](https://github.com/BwL1289/opensource-content/tree/87480719db0871c6b467a16437919d1df84055ed/src/equity_equation).
